## 🧠 Problem-Solving Approach

For many problems, I try to understand and implement different approaches rather than directly jumping to the optimal solution.

### Typical progression

```text
Problem
   ↓
Understand the concept
   ↓
Brute Force Approach
   ↓
Analyze Time & Space Complexity
   ↓
Optimize the solution
   ↓
Implement & Test
```

This helps me understand **why an optimized solution works**, instead of simply memorizing it.

---

## ⚡ Complexity Analysis

I am also practicing analysis of:

* ⏱️ Time Complexity
* 💾 Space Complexity
* Big-O notation
* Brute force vs optimized approaches

Example:

| Approach    | Time Complexity | Space Complexity |
| ----------- | --------------- | ---------------- |
| Brute Force | O(n²)           | O(1)             |
| Optimized   | O(n)            | O(1)             |
